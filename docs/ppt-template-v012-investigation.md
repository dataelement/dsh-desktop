# V0.12.0 PPT 模板转换与预览根因

范围：PPT 模板上传、内置／个人模板预览、布局可读性和加载反馈。当前 PR 基线、用户验收与检查结果见 [交付状态](STATUS.md)，完整支持范围见 [能力审查](ppt-template-conversion-review.md)。

## 预览与选择

原卡片点击调用 `choose(template)`，只能选中模板。两份客户端现在共用维护组件：独立小眼睛打开高清、逐页查看的弹窗；“做同款”在查看后调用原有选择路径。预览使用实际导出 PPTX 的 Office 页图。底图与内部内容按统一画布缩放，默认完整适配容器，翻页重置框内双指缩放。

导入进度以实际完成的页图发布，预览区展示逐页缩略图，右下角显示数量。第一张完整页图加载后显示一次成功动效；该状态由草稿生命周期管理，会话切换和关闭时清理。

## 字体与文本布局

源文件的字体、字号与颜色可以来自 slideLayout／母版占位符的 `lvl1pPr/defRPr`，原转换只读取局部 `run/rPr`。转换现在按继承层级合成默认样式，局部显式属性覆盖继承值；字体槽解析到实际脚本字体，源段落、制表、字符间距、文本框标记和透明度进入原生导出。

固定文本框内的自动撑大规则转换为 `normAutofit`，由 Office 在源框尺寸内适配文字；显式 `noAutofit` 保持。源自动适配规则另行记录。字体环境通过中文字体预载及常见别名匹配统一，源工程继续保留作者声明的字体。跨平台字体替换可能改变字宽，相关视觉验收单列。

## 组合与主题

组合的 `chExt` 描述局部几何坐标，字号 `rPr.sz` 与线宽 `ln.w` 使用物理单位。原展开逻辑把三者一起缩放，局部组坐标可以把 1pt 边框放大为遮挡页面的色块。当前逻辑对位置与尺寸合成仿射变换，同时保留字体和线宽单位。实际嵌套组合对照验证了 12pt 文字的像素边界。

连接符局部 `ln` 可能只包含端点，完整样式来自主题 `lnRef`。转换合成主题样式矩阵及局部覆盖，解析 `phClr` 引用色，并保留宽度、虚线和箭头。187 种标准几何与自定义路径通过 DrawingML 导出；母版及版式中的可见装饰与背景按源顺序合成。

## 对象与资源覆盖

解析器可能省略 SmartArt、OLE、现代图表或未知绘图对象。转换前独立枚举源 `spTree`，转换后核对绘制顺序；有效位置的映射缺口进入可替换占位。非正交组合按完整四角变换计算占位外接框，图片／播放资源按源位置、尺寸、旋转、翻转和层级占位，模板保留原 PPTX 与页码原因。

ZIP 预检在解码前限制单项媒体大小，图像解码限制像素总量，缓存相同资源的校验结果。包结构、总资源预算和有效边界继续执行输入门禁。图片四边 `srcRect`、常见背景、图表 `pt idx` 空缺贯通模型与可编辑导出。

## 导出与性能

完整预览采用 PPTX → LibreOffice PDF → PDFium，直接反映最终转换输出的版式。原段落、几何和样式按模型摘要保留；作者修改后，对应属性使用当前模型导出。媒体内容去重、关系重定向、逐页单次 XML 处理和整稿单次压缩减少重复工作，第一张页图优先发布，后续按小批次栅格化。

转换版本 7／预览版本 8 支持原稿重传重建并保留备份。原稿视觉保真、复杂表格／图表、SmartArt 缓存布局与存量自动批量迁移按能力矩阵继续验收。
