## 已实施

- 母版／版式文本继承、字体与主题颜色、原生段落和文本框自动适配贯通导入与可编辑导出。组合仅变换几何坐标，字体和线宽保留物理单位。
- 187 种 DrawingML 预设、自定义路径、连接符、主题填充与线条、图片四边裁剪及常见背景保留原生属性。源对象覆盖清单核对数量与层级。
- 具备有效位置的未知图形、解析遗漏对象、非正交组合、异常图片及播放媒体使用可替换占位，并记录页码、位置和原因；正常相邻对象继续转换。结构损坏和资源预算执行输入门禁；原 PPTX 完整保留。

- 分类为“全部”、内置分类、“自定义”；首卡提供创建入口，自定义模板排在内置模板后。小眼睛预览与选择分开，翻页和底部操作简化，支持预览框内双指缩放、“做同款”以及完整预览首次出现的成功动效。
- macOS 侧栏在已有窗口主题接缝中采用 Harness 语义背景，避免原生材料底色造成历史列表变灰。中英文、深浅主题和减少动态效果路径由共享客户端维护。
- 转换版本 7 / 预览版本 8：相同原稿重传重建并保留旧版本备份。支持矩阵、剩余覆盖与验收方法见 [转换审查](ppt-template-conversion-review.md)。
