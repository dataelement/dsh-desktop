## 原有行为：保持不变

- 创建选题或 Campaign 只保存业务记录，不自动建会话。用户通过工作台或业务抽屉里的“新建会话”创建对应会话。
- 创建会话时使用 `projectRoot` 创建工作区，保存 workbench/topic/campaign 绑定，在空草稿中填入开场提示词，不自动发送。
- 四个窗口包含原生聊天，保留拖动、缩放、收起、恢复、放大及原有业务工具栏。
- 没有会话也可使用业务面板。选题、达人、Campaign、日历、采集、图表和标注功能不作业务改造。
- 三个工具继续按 Agent 会话注册并校验业务绑定；数据与浏览器登录资料不迁移、不打包。

## 验收

- 新用户无会话时能看到并使用业务面板。
- 创建选题/Campaign 不额外创建会话；点击对应新建会话入口后创建工作区、原生会话并登记业务 scope 和工作台归属。
- 开场提示词不覆盖已有草稿，也不自动发送。
- 恢复已有会话保留业务映射；删除后的会话可明确报错并由用户新建。
- 隐藏工作台不抢焦点或写入其他会话；关闭只退出视图，不停止后台任务。
- 四窗布局及原生聊天保留，输入挂载不重复。
- 校验打包清单、版本、依赖和校验和；仅将验证后的安装包加入本地市场。
