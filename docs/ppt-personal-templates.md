# 个人 PPT 模板

用户在 PPT 模式的“全部”分类首张卡片上传 PPTX，逐页预览后保存为当前 Desktop 配置目录中的个人模板。“全部”按创建入口、自定义模板、内置模板排列，自定义模板按创建时间从新到旧排序。“自定义”分类位于标签末尾，用于快速筛选。新模板保存后自动选中；后续会话可选择同一模板。模板卡片名称单行省略，悬停显示全文。卡片的编辑与删除入口在悬停或键盘聚焦时出现，编辑通过弹窗修改名称和描述。左上角的小眼睛与右上角的编辑、删除入口同层显示于选中蒙层上方，顶边对齐。

## 导入与复用

1. 客户端按 8 MiB 分片写入 Host 临时上传目录，`template/prepare` 接收该会话的上传标识；兼容 Base64 输入，验证 PPTX、上传数据和独立 200 页导入预算，在 Host 侧完成转换和审计。文件大小沿用 Host 通用传输与解压资源限制。
2. PPTX 通过 OOXML 关系解析为 PPTD 页面、图片和图表。组合对象先合成完整坐标变换再展开；图片资源支持安全 SVG、常见位图，以及受限的 EMF 矢量路径与裁剪。
3. 抽取原稿的字体、字号、颜色、粗体和配色，按实际页面元素生成用途与可替换位置索引；原页面内容和布局保留用于预览与复用。生成最长边 1920px 的逐页预览，以及三张最长边 720px 的目录缩略图。大图片在预览时生成符合显示尺寸的临时副本，保持透明度和裁切，模板与导出保留原图。弹窗用于翻页、命名、保存和取消。
   处理中的缩略图区展示最多四行，按实际卡片与页码高度计算边界，随窗口宽度重新测量；更多页面通过区域内滚动查看。短窗口按可用高度提前滚动，进度与底部操作固定在缩略图区外。新增页图后自动滚动至最新页，窗口重新测量后继续显示列表底部，支持键盘聚焦及滚动。处理完成后直接显示模板示例预览，用户可立即翻页、缩放或保存；图片读取失败时提供重试入口，保存完成显示轻量确认消息。
4. `template/save` 校验后将草稿原子移入已保存目录。原稿 SHA-256 用于重复文件识别；同一配置目录最多保存 100 套模板。草稿属于创建它的会话，过期草稿按限额清理。
5. 用户选择模板后，`ppt_template_create_project` 通过现有工作区路径策略与审计创建独立副本，使用抽取的原稿主题。`ppt_get_template_reference` 提供配色、字体和页面结构，`ppt_get_template_pages` 的完整索引提供简洁用途与数量，指定页读取提供元素 ID、边界、文本样式、换行与自动适配属性。Agent 据此选择实际页面、替换业务示例，再使用现有 PPTD 工具检查和导出可编辑 PPTX。

模板库位于 `<Host root>/personal-templates`；它随当前 Desktop 配置目录保存。组织共享、跨设备同步和账号级云端模板库尚未实现。上传资料和模板示例属于不可信内容，Agent 应按当前用户任务处理示例文字与数据。

## 可复用的模板结构

结构索引版本为 1，配色和标题／正文样式来自实际页面与富文本运行。每个内容槽关联真实元素 ID 和位置，标记标题、正文、页脚、背景、图片、图表或表格，以及替换内容／检查品牌元素的操作。页面用途按几何特征推断为封面、数据、视觉、多块或正文页；重复文字与页边文字用于提示品牌／页脚检查。文本容量是按源字号与框宽估算的改写参考，实际内容仍通过原有布局检查与导出预览确认。

结构索引直接与原页面关联。标题／正文默认样式及配色写入工程主题，元素自身的原始样式优先。原稿文字、页面、图片和资产继续随模板保存，供预览和内容改写使用。当前转换／预览版本的重复文件复用现有页图；缺少结构索引的旧记录按已经保存的页面补充元数据并原子更新，后续预览直接使用原有结果。

## 处理性能

上传预览采用一次 PPTX 导出与 Office 转 PDF。首页先完成并发布，后续按 8 页批次生成页图以减少原生调用次数；同一导入中的母版、版式及关系共用只读解析结果。目录缩略图的首页、中页、尾页任务去重；准备和保存各读取一次模板库。

本机三份 39／24／18 页原稿的总处理耗时由 30.91／16.02／11.88 秒变为 26.47／14.73／10.92 秒。总耗时受文件内容、机器和缓存影响；同一 PDF 的交替批次测试中，热缓存页图阶段约快 21%，39 页 PNG 字节一致。数据及客户端验收边界见 [交付状态](STATUS.md)。

## 转换与验证

Host 与 CLI 共用转换模块。内部对象 ID 由遍历顺序生成，独立于可能重复的显示名称。连接符保留原生 DrawingML 几何。字体、富文本字号和自动适配尽量沿用源对象；原对象内容指纹区分已存在的布局问题和改写后的严格检查。

图片格式、资源关系、解码或处理限额，以及图形／图表映射遇到问题时，转换器在原边界、旋转、翻转和层级插入可替换的图片槽。占位为半透明白底、浅灰虚线边界和简洁图片符号；视频、音频使用播放符号。非正交组合使用完整变换后的外接框。转换器按源页面对象清单核对解析结果，SmartArt、嵌入对象或其他绘图对象的解析遗漏进入同一占位规则。其他对象继续转换，预览和导出共用占位资源。模板记录的 `resourcePlaceholders` 保留页码、对象、边界和原因，上传预览显示一条轻量提示，原始 PPTX 随模板完整保存。占位表达对象位置，用户可在导出的 PPT 中替换实际内容。

资源读取在 ZIP 解压前识别超过 16 MiB 的单项图片及播放资源，按其 OOXML 位置占位；图像解码限制为 20 MiPixels（含动图页数），相同资源在一次导入中共用校验结果。保留包级数量、结构文件大小和总解压资源限额，非法包结构及无效对象边界继续返回可定位的错误。转换版本 8 / 预览版本 9 支持旧模板重传刷新并保留备份。

EMF 接收已实现的二维绘图记录，支持路径、贝塞尔曲线、实色画刷、线条和裁剪。文件大小、记录数量、路径点数、状态栈和裁剪层级均有上限。EMF+ 和转换范围外的绘图记录进入图片占位；组合倾斜变换按受影响对象占位。原生 DrawingML 几何、四边图片裁剪、常见背景及图表缓存空缺贯通可编辑导出。复杂文字变形和部分 OOXML 样式按明确能力简化，视觉保真需要核对实际原稿。完整能力矩阵、已实施修复和后续门禁见 [PPT 转模板能力审查](ppt-template-conversion-review.md)。

个人模板 PPTX 采用 Host 通用传输与解压预算。审查预览按页读取，目录缩略图仍为每套 3 张 720px 图。自动化覆盖超过 64 MiB 的真实图片 PPTX 导入、资源预算、保存与复用、格式及数据校验、会话与路径隔离、重复文件、保存/取消、编辑/删除、选择持久化、独立工程复制、原生导出、异步状态、弹窗、长名称、富文本、字体、图表、安全 SVG、EMF 和嵌套组合。仓库合成测试不包含用户原稿。

开发验证另外使用了两份企业原稿（共 53 页）和 56 份已有本地样本。企业原稿在实际包内 Host 完成导入、高清预览、保存、重载、复制和导出；此前样本通过批量转换检查。原稿、客户资源和本地安装包作为开发机证据保存。

## 内存与执行隔离

Host 验证完整上传后，在库锁与审计范围启动有界导入进程。逐页预处理、惰性模型、流式图形合法性检查和有界 DOM 缓存控制临时内存；超过几何预算的路径提前进入原位置占位。处理进程的 V8 预算为 1536 MiB，总超时为 10 分钟；预算耗尽或超时返回可重试的导入错误，其他 Host 功能继续运行。进度和模板结果通过 IPC 返回，原稿及素材留在受控目录。完整准备失败清理上传及本任务草稿，尚未传完的上传可继续传输。
