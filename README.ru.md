DSH Desktop превращает локальный DeepSeek Harness в устанавливаемое настольное приложение. Оно автоматически запускает Harness, хранит Profile, плагины, рабочие пространства, настройки моделей и сессии вне каталога приложения и открывает полный интерфейс Harness, когда локальный Runtime готов.

> [!IMPORTANT]
> DSH Desktop — ранняя предварительная версия на основе быстро развивающегося `@deepseek-ai/dsh@0.1.5-rc.2`. Выпуски для macOS подписаны и нотариально заверены Apple. Установщики Windows x64 также подписаны; предупреждения безопасности Windows могут уменьшаться постепенно по мере накопления репутации загрузок и установок.

## Загрузка

Мы предлагаем стабильные и предварительные версии: **стабильную версию**, рекомендуемую для повседневного использования, можно скачать с [официального сайта](https://www.dshdesktop.com/#download). Чтобы попробовать **предварительную версию**, выберите выпуск с отметкой **Pre-release** на [GitHub Releases](https://github.com/dataelement/dsh-desktop/releases).

Предварительные версии включают наши новые функции и активно переходят на последние официальные версии DeepSeek Harness. Они могут быть несовместимы с плагинами сообщества и **не рекомендуются обычным пользователям**. Желающих первыми попробовать новинки приглашаем тестировать их и делиться отзывами в сообществе. Мы распространяем обновления среди всего сообщества только после проверки первыми пользователями.

Установленные версии проверяют обновления вскоре после запуска и затем каждые шесть часов. При появлении новой версии DSH Desktop сначала запрашивает согласие: загрузка начинается только после подтверждения, а установка — после выбора **Restart and install**. Можно проверить обновления вручную или пропустить одну версию, не отключая уведомления о следующих.

## Что добавляет DSH Desktop

DeepSeek Harness уже предоставляет Agent Runtime и Web UI. DSH Desktop добавляет возможности нативного хоста, необходимые настольному продукту:

- Запускает и останавливает Harness без отдельной CLI или вкладки браузера
- Использует системный выбор каталогов для добавления и управления рабочими пространствами
- Поддерживает официальные модели DeepSeek и популярные сторонние поставщики моделей
- Импортирует и экспортирует пользовательские Agent Preset как переносимые [пакеты `.dshpreset`](docs/preset-packages.md)
- Превращает исходные материалы в редактируемые презентации PPTX во встроенном режиме PPT
- Сохраняет Profile, плагины, рабочие пространства, сессии и настройки моделей при обновлении приложения
- Обнаруживает сбои запуска и ошибки плагинов интерфейса, сохраняет диагностику и предлагает управляемое восстановление
- Предоставляет неразрушающий безопасный режим, временно блокирующий сторонние плагины
- Позволяет подключённому телефону продолжать сессии через LAN или необязательный временный публичный туннель
- Проверяет обновления приложения и оставляет загрузку и установку под контролем пользователя
- Адаптирует меню, заголовок окна, фокус, тему и оформление для macOS и Windows

## Создание PPT

Включите кнопку **PPT**, выберите шаблон и опишите нужную презентацию. Встроенный каталог содержит **16 шаблонов и 192 макета** с экспортом в редактируемый PPTX. Предпросмотры представлены на английском; презентации могут быть на английском или китайском с соответствующими настройками шрифтов. Язык предпросмотра не определяет язык результата.

PPT установлен заранее. Его автоматические инструкции применяются только к сессиям с включённой кнопкой PPT. Подробнее о шаблонах, проверках и источниках — в [руководстве PPT](packages/ppt-runtime/README.md).

## Подключение телефона

Выберите **Connect Phone…** в меню `Harness` и отсканируйте код. Перед доступом телефона к сессиям требуется явное подтверждение на компьютере.

Сам Harness остаётся на случайном порту `127.0.0.1`. Телефон использует отдельный Bridge с подтверждённым сопряжением: можно ограничиться локальной сетью или включить временный Cloudflare Quick Tunnel для удалённого доступа.

Если Cloudflare не запускается, приложение пробует Pinggy. Если ссылка Cloudflare уже появилась, но телефон не может её открыть, выберите **Can’t open? Try another link**, чтобы переключиться на Pinggy.

## Безопасный режим и восстановление

Если сторонний плагин мешает запуску или отображению интерфейса, DSH Desktop сопоставляет данные Runtime и фронтенда с установленными плагинами и открывает управляемое восстановление.

Команда **Restart as Safe Mode…** в меню `Harness` запускает изолированный Profile только с официальными основными Bundle. Сторонние плагины обычного Profile блокируются, но Agent, сессии, настройки моделей и рабочие пространства остаются доступными.

Экран восстановления проверяет наличие совместимых обновлений плагинов и позволяет установить доступное обновление. Безопасный режим также поддерживает групповое обновление. Для помощи наведите указатель на **WeChat group**, чтобы увидеть QR-код, или нажмите **Discord**, чтобы открыть сообщество.

Если обычный интерфейс не открывается, запустите приложение с `--safe-mode`. Пример для macOS:

```sh
open -a "DSH Desktop" --args --safe-mode
```

## Локальные данные и безопасность

- Web UI Harness доступен только на случайном loopback-порту.
- Renderer не имеет прав Node.js и работает с Context Isolation и sandbox.
- WebView, недоверенная навигация внутри приложения и неожиданные запросы разрешений блокируются.
- Profile и сессии хранятся в пользовательском каталоге данных приложения, а не в каталоге установки.
- Для телефона требуются краткосрочный Token и явное подтверждение на компьютере.

## Поддерживаемые платформы

| Платформа | Формат | Статус |
| --- | --- | --- |
| macOS Apple Silicon | Подписанные и нотариально заверенные DMG/ZIP | Поддерживается |
| macOS Intel | Подписанные и нотариально заверенные DMG/ZIP | Поддерживается |
| Windows x64 | Подписанный установщик NSIS | Поддерживается |
| Windows ARM64 | — | Не поддерживается |
| Linux | — | Не поддерживается |

Harness содержит нативные зависимости, поэтому каждый выпуск собирается на соответствующей операционной системе и архитектуре.
