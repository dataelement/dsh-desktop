## Что добавляет DSH Desktop

DeepSeek Harness предоставляет Agent Runtime, Web UI и базовое подключение моделей. DSH Desktop развивает эти возможности:

- **Интеграция моделей**: улучшенная первоначальная настройка, поиск моделей, настройка ввода изображений и рассуждения, совместимость со сторонними моделями.
- **Шаблоны Office**: редактирование нативных шаблонов Word, примеры книг Excel и редактируемые шаблоны PPT вместе с бизнес-навыками для создания DOCX, XLSX и PPTX; Python и зависимости Office включены.
- **Восстановление после сбоев**: диагностика запуска и интерфейса, управляемое восстановление, безопасный режим и доступ к Agent для исправлений с приоритетом сохранения сессий и настроек.
- **Workbench**: просмотр, установка из каталога или локальный импорт и запуск приложений с использованием диалогов Harness.
- **Перенос Preset**: импорт и экспорт [пакетов `.dshpreset`](docs/preset-packages.md) с проверкой конфликтов и предупреждениями о доверии.
- **Подключение телефона**: сопряжение по QR-коду и продолжение сессий через LAN или необязательный публичный туннель.
- **Настольная интеграция**: управление запуском Harness, системный выбор каталогов, нативные меню и окна, сохранение данных и автоматическая проверка обновлений.

## Пакет Office

Выберите режим Word, Excel или PPT, шаблон и исходные материалы — Agent создаст редактируемый файл.

- **Word**: сохранение оформления нативных шаблонов для уведомлений, протоколов и отчетов с выводом DOCX.
- **Excel**: данные, анализ и диаграммы на основе примеров рабочих книг с выводом XLSX.
- **PPT**: **16 встроенных шаблонов и 192 макета**, редактируемый PPTX и импорт личных шаблонов. Встроенные превью — на английском, презентации — на английском или китайском; язык превью не определяет язык результата.

Python и зависимости Office включены в приложение и не требуют отдельной установки. Автоматические инструкции режима шаблонов PPT действуют только при его включении в текущей сессии.

## Workbench

Workbench объединяет специализированный рабочий интерфейс с диалогами Agent, предлагая больше, чем обычный чат.

Просматривайте, добавляйте в избранное и устанавливайте приложения из каталога или импортируйте локальную разработку. Используйте рабочий интерфейс вместе со связанными диалогами Agent; после установки или обновления перезапустите приложение по подсказке. Удаление Workbench сохраняет существующие сессии и файлы проекта.

## Подключение телефона

Выберите **Connect Phone…** в меню `Harness` и отсканируйте QR-код. По Wi-Fi подключение происходит сразу; через интернет также введите 6-значный пароль с компьютера. По умолчанию пароль действует 5 минут; постоянный пароль сохраняется только с вашего согласия в окне подключения.

Можно использовать LAN или временный публичный туннель. При недоступности Cloudflare используется Pinggy; бесплатный Pinggy действует около 60 минут.

Если Cloudflare не запускается, приложение пробует Pinggy. Если ссылка Cloudflare уже появилась, но телефон не может её открыть, выберите **Can’t open? Try another link**, чтобы переключиться на Pinggy.

## Безопасный режим и восстановление

Если сторонний плагин мешает запуску или отображению интерфейса, DSH Desktop сопоставляет данные Runtime и фронтенда с установленными плагинами и открывает управляемое восстановление.

Выберите **Restart as Safe Mode…** в меню `Harness`, чтобы временно блокировать сторонние плагины, сохранив Agent, сессии, настройки моделей и рабочие пространства. Отключите проблемный плагин на экране управления и перезапустите обычный режим для проверки. Отключение не удаляет плагин и данные; позже его можно включить снова.

Экран восстановления проверяет наличие совместимых обновлений плагинов и позволяет установить доступное обновление. Безопасный режим также поддерживает групповое обновление. Для помощи наведите указатель на **WeChat group**, чтобы увидеть QR-код, или нажмите **Discord**, чтобы открыть сообщество.

Если обычный интерфейс не открывается, запустите приложение с `--safe-mode`. Пример для macOS:

```sh
open -a "DSH Desktop" --args --safe-mode
```

## Локальные данные и безопасность

- Сессии и настройки хранятся локально в пользовательском каталоге и сохраняются при обновлении приложения.
- Встроенный боковой браузер изолирован от привилегий приложения; обычные внешние ссылки открываются в системном браузере.
- Телефон подключается сканированием кода; для подключения через интернет также нужен пароль, отображаемый на компьютере.
- Файловые операции и команды Agent контролируются разрешениями. Осторожно подтверждайте важные действия и устанавливайте только доверенные плагины.

| macOS Apple Silicon | Подписанные и нотариально заверенные DMG/ZIP | Поддерживается |
| macOS Intel | Подписанные и нотариально заверенные DMG/ZIP | Поддерживается |
| Windows x64 | Подписанный установщик NSIS | Поддерживается |
| Windows ARM64 | — | Не поддерживается |
| Linux | — | Не поддерживается |

## Узнайте о корпоративной версии

Корпоративная версия состоит из настольного клиента BISHENG и сервера корпоративной платформы BISHENG. Клиент на базе DSH Desktop позволяет работать с локальными файлами и разрешенными моделями, знаниями, инструментами и навыками через корпоративную учетную запись. Сервер централизованно настраивает ресурсы и права, управляет кредитами и использованием. Клиент и сервер BISHENG для корпоративной версии имеют открытый исходный код, доступный в репозиториях ниже.

[Исходный код платформы управления](https://github.com/dataelement/bisheng) · [Репозиторий корпоративного клиента](https://github.com/dataelement/bisheng-desktop) · [О корпоративной версии](https://www.dshdesktop.com/ru/enterprise/)
