# 提示词效果回流记录（配套素材）

> 版本：v1　|　建立日期：2026-09-01　|　归属：公文写作技能包 · 配套素材库
> 定位：将"每一次公文写作任务"转化为"技能包自我进化"的数据源。本文件是**机制说明 + 流水台账模板**，真实记录追加于文末"■ 回流记录"区。

---

## 一、为什么要回流（机制价值）

技能包不是一次写就的静态物。L0~L5 七层资产在真实任务中会暴露三类问题：
1. **提示词失效**：`06_资产册`的提示词模板在某类文种/场景下发不出好稿，需修订话术。
2. **素材缺口**：`04_素材册`缺某类句式/提纲，或`配套素材库`缺某文种范文。
3. **规则冲突/过时**：`02_规则册`某条政治表述或`04_素材册`某指标口径已随外部现实变化（如会议届次、五年规划、考核口径），需按第三轮排查机制更新。

没有回流，技能包会随时间腐化（前两轮自查只查内部一致性，第三轮才补"与外部现实一致性"，正是因为没有常态化回流）。

## 二、何时记、记什么（运行节奏）

**触发点**：每完成一次正式公文写作任务（或一批同类任务）后，**立即**追加一条记录，不要等周报时回忆。

**每条记录必含字段**（复制下方模板填写）：

```
■ 回流记录 #序号 | 日期：YYYY-MM-DD | 任务类型：〖通知/报告/请示/函/方案/其他〗
- 使用的资产：06_资产册的〖提示词模板名〗；参照素材：〖配套素材库文件/章节〗
- 六维自评（1-5分，可简写）：
    政治性__ 合法性__ 真实性__ 逻辑性__ 表达性__ 实效性__ ｜ 安全性红线：通过/触发__
- 排雷闸门：真实核验__ 安全审查__ （是否触发拦截/返工）
- 卡点/返工点：〖具体描述，如"请示尾语用了报告用语""数据未标来源被客户打回"〗
- 客户/自身体感：〖"一次过"/"改2轮才过"/具体好评或差评〗
- 改进建议（落到具体文件）：
    □ 修订06_资产册提示词：〖哪条、怎么改〗
    □ 增补04_素材册：〖缺什么句式/提纲/指标〗
    □ 增补配套素材库范文：〖缺哪文种/哪子类〗
    □ 更新02/04册规则：〖哪条已过时，外部依据是什么〗
    □ 无需改动
- 处理状态：待办 / 已并入vX.X.X / 已关闭
```

## 三、回流如何落进技能包（闭环路径）

| 发现的问题 | 落到哪 | 谁来做 | 节奏 |
|------------|--------|--------|------|
| 提示词语序/措辞不佳 | `06_资产册`对应模板 | 维护者 patch | 下次版本迭代 |
| 缺句式/提纲/指标 | `04_素材册` | 维护者 patch | 季度补充 |
| 缺范文样本 | `配套素材库/范文样本_*` | 维护者 fetch+脱敏 | 按需 |
| 政治表述/指标口径过时 | `02_规则册`/`04_素材册`（标"每年须核对"项） | 维护者+业务负责人确认 | **年度核对 + 重大会议后即时** |
| 格式版式疑问 | `05_格式册`/`配套素材库/格式样板件_*` | 维护者 patch | 按需 |

**版本约定**：每次对运行册（0X_v202_*.md）做实质性 patch，按"v202 → v203 → …"递增；旧版移入`vXXX_留档_YYYYMMDD/`（只移不删，遵循铁律）。重大结构变更另开新册并在`项目管理/`留审计脚本。
