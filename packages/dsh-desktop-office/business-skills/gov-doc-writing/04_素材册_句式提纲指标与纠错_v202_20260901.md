# 第 1 编　L4 句式提纲库

## 公文写作技能包 · L4 素材层（句式化提纲库与生成规则）

> **本层定位**：给 AI 提供可直接套用的段落骨架句式与实例。这一层的作用是**润色与提速**，不决定对错（对错由 L0、L1 决定）。
> **资料来源**：公开素材库「写作百科 → 写作提纲」（共 100 份同类件），本次提炼其句式规律 + 抽取 45 组实例。
> **建立日期**：2026-08-31

---

### 1. 核心发现：公文提纲的句式是有规律的

分析 100 份提纲件后发现，所谓"好提纲"并不是靠灵感，而是**一套高度可复用的句式模板**在换词。规律如下：

```
一篇公文的段落骨架 = 总起句（定调） + N 个并列分述（展开） + [可选] 收束句
                        ↑                    ↑
                   6 种固定范式        3 种固定范式
```

**这意味着：只要给定「统领词 × 业务领域 × 想要的效果」，就能机械生成合格提纲。**
这也解释了为什么 AI 写公文容易"没那味儿"——它缺的不是语料，是这套句式约束。

---

### 2. 总起句：6 种范式

设统领词为 **X**（如"深化""创新""突出"），业务领域为 **D**，目标为 **G**。

| 范式 | 结构 | 示例 |
|---|---|---|
| P1 直陈式 | 「N个X」+ G | "三个深化"推动精神文明建设走深走实 |
| P2 抓手式 | 以「N个X」为抓手，+ G | 以"三个深化"为抓手，全力推进查究整改走深走实 |
| P3 聚焦式 | 聚焦 N 个「X」+ D | 聚焦三个"深化" 护航乡村振兴 |
| P4 抓实式 | 抓实「N个X」保障 G | 抓实"三个深化" 保障营商环境持续优化 |
| P5 助推式 | 用/以「N个X」助推 D | 以"三个深化"助推"我为群众办实事"实践活动 |
| P6 践行式 | 践行「N个X」提升 D | 践行"三个深化"提升工业统计工作质效 |

**选择规则**：
- 汇报成绩、总结经验 → 优先 P1、P6
- 部署工作、提出要求 → 优先 P2、P4
- 强调重点、突破难点 → 优先 P3、P5

### 3. 分述句：3 种范式

| 范式 | 结构 | 字数 | 示例 | 适用场景 |
|---|---|---|---|---|
| **A 简式** | X + 名词短语。 | 8—12 字 | 深化文明创建。 | 简报、信息、短材料 |
| **B 中式** | X + 名词，+ 效果短语。 | 14—20 字 | 深化建章立制，加快"全"的步伐。 | 常规总结、讲话 |
| **C 全式** | 一是 X + 名词短语，+ 效果句。 | 18—26 字 | 一是深化队伍建设，夯实组织基础。 | 正式报告、汇报材料 |

**效果补语常用库**（B、C 式的后半段）：

| 类型 | 四字 | 六字 | 八字 |
|---|---|---|---|
| 程度 | 持续增强、全面提升、不断深化 | 走深走实、见行见效、落地生根 | 质效双升、稳中有进 |
| 状态 | 夯实基础、筑牢根基、激发活力 | 凝心聚力、同频共振、同向发力 | 蹄疾步稳、行稳致远 |
| 结果 | 成效显著、亮点纷呈、成果丰硕 | 提质增效、提档升级、扩面提质 | 落地见效、开花结果 |
| 比喻 | 打通堵点、补齐短板、强弱项 | 牵住牛鼻子、下好先手棋 | 打通最后一公里 |

### 6. 单字统领式提纲（进阶）

从"三个突出"提炼出的高级句式：

```
突出一个「单字」，+ 抓好/做好「动作」
```

**常用单字库**：
| 字 | 含义 | 搭配 |
|---|---|---|
| 深 | 程度深 | 大学习、理论武装、调查研究 |
| 准 | 方向准 | 问题查找、政策落实、对象识别 |
| 实 | 成效实 | 大实践、整改落实、为民服务 |
| 全 | 覆盖全 | 摸排、培训、监督 |
| 快 | 节奏快 | 响应、办理、处置 |
| 稳 | 底盘稳 | 风险防控、基本盘 |
| 严 | 要求严 | 执纪、标准、管理 |
| 新 | 思路新 | 载体、方法、机制 |

---

### 7. AI 调用规则（写进提示词）

生成提纲时必须遵守：

1. **先定统领词**：从统领动词表按语义选（推进/建设/创新/聚焦/落实/保障）
2. **再定范式**：总起句 6 选 1，分述句 A/B/C 三选一（按篇幅和正式程度）
3. **并列项必须同构**：三个分述的语法结构、字数节奏必须一致（这是最容易被 AI 写坏的地方）
4. **每项必须含领域词**：不能只写"深化认识"这种空话，要写"深化税费业务'提速办'"
5. **效果补语不重复**：同一段内避免重复使用同一个四字词
6. **禁止生造**：不使用"赋能""抓手"以外的生造词，不使用网络流行语
7. **数量与内容匹配**：确实只有三点才用"三个"，不要硬凑或硬删

> **配套**：本册第 1 编《L4 句式提纲库》（范式与统领动词表在此，本编不重复）、第 1 册第 2 编《公文质量检查手册》、本册第 5 编《病文纠错库》。

---

## 第一部分　使用红线（先看这里）

金句与提纲是**调料不是主菜**。用错比不用更糟。

| 红线 | 说明 |
|---|---|
| **不堆砌** | 一篇 3000 字材料，排比句不超过 2 处、金句不超过 3 处。堆砌即"AI 味" |
| **不生造** | 不用网络流行语、不用自造的四字短语、不用"赋能""闭环"以外的生造词 |
| **同构必须严格一致** | 三个并列项的语法结构、字数节奏必须一致，这是提纲写坏的第一原因 |
| **数量必须匹配内容** | 确实只有三点才写"三个"，不要硬凑硬删 |
| **引用必须核对原文** | 领导讲话、政策原文、古籍名句一律核对后再用，记不准就改写为普通表述 |
| **金句不能替代事实** | 一段里全是漂亮话而没有数据、责任、时限，属实效性不合格 |
| **不用险句** | 涉及政治评价、个人褒贬、绝对化判断的句子一律不用 |

### 2. 过渡句（按逻辑关系，30 条）

> 过渡句的作用是**让读者知道下文要讲什么、为什么转到这里**。用错逻辑的过渡句比不用更糟。

#### 2.1 递进（由浅入深、由点到面）

```
1.  在此基础上，还要看到……
2.  不仅要解决好{{具体问题}}，更要从{{机制/制度}}层面加以解决。
3.  成绩固然可喜，但更要清醒地看到，我们的工作还存在不少差距。
4.  这是第一步，更关键的是第二步——{{ }}。
5.  由此及彼，由此及里，我们还应看到……
```

#### 2.2 转折（指出问题、转入不足）

```
6.  在肯定成绩的同时，我们也清醒认识到，{{工作}}还存在一些不容忽视的问题。
7.  对照{{上级要求/群众期盼/先进标杆}}，我们的工作仍有不小差距。
8.  但也要看到，{{问题}}尚未根本解决，{{现象}}仍时有发生。
9.  问题是时代的声音，也是工作的导向。当前最突出的是以下三个方面。
```

#### 2.3 并列（分条展开）

```
10. 具体来讲，要抓好以下{{N}}个方面。
11. 重点要把握好以下几个环节。
12. 归纳起来，主要是"{{N}}个{{统领词}}"。
13. 从{{维度}}看，主要有{{N}}个方面。
```

#### 2.4 因果（由因及果、由果溯因）

```
14. 之所以出现这些问题，根子在于{{思想认识/责任落实/机制保障}}不到位。
15. 正是因为{{做法}}，才有了{{成效}}。
16. 究其原因，主要有三点：一是……二是……三是……
17. 基于以上分析，我们必须{{结论/对策}}。
```

#### 2.5 总—分 / 分—总

```
18. 总的考虑是：{{总体思路}}。具体分{{N}}个方面推进。
19. 以上三个方面，归结起来就是要{{一句话概括}}。
20. 概括起来讲，就是"{{几个字概括}}"。
```

#### 2.6 时间推进（阶段转换）

```
21. 第一阶段重点解决{{ }}，第二阶段着力推进{{ }}。
22. 起步阶段重在{{ }}，攻坚阶段重在{{ }}，收官阶段重在{{ }}。
23. 从{{时间节点}}起，工作重心将转向{{ }}。
```

#### 2.7 强调（突出重点）

```
24. 这里我要特别强调{{ }}。
25. 其中，最关键的是{{ }}，最紧迫的是{{ }}。
26. 重中之重，是要解决好{{ }}。
27. 这一点，怎么强调都不为过。
```

#### 2.8 收束到行动

```
28. 说一千道一万，落实是关键。
29. 蓝图已经绘就，关键在于落实。
30. 任务已经明确，责任已经分解，接下来就是抓落实。
```

# 第 3 编　量化指标体系库

## 公文写作技能包 · 本册第 3 编《量化指标体系库》（P1 素材层 · 修正版）

> **定位**：解决"写目标时给不出可信指标"——审计报告判定实效性仅 4/10 的根因。本库让 AI 在生成含"目标任务"要素的文种时，能套用合规、可考核的指标范式。
> **边界**：通用党政机关 + 国有企业通用框架（不含任何单行业专属指标，本包保持通用）。
> **对应缺口**：审计 P1-4（本册第 3 编《量化指标体系库》）。
> **配套调用**：第 1 册第 1 编《生成前准备手册》第②步（要素核对后取指标范式）；第 1 册第 2 编《公文质量检查手册》"实效性"项（目标可量化可考核 → 对照本编）。
> **红线**：本库只提供"指标类型 + 口径 + 表述范式"。**所有实际数值必须由用户提供**，AI 不得编造、不得用看似合理的数据填充。未填处一律标注 `【待补充：请提供 XX 指标的实际值】`。

## 0. 调用方式（AI 自检流程）

```
文种含"②目标任务"要素？
   ├─ 否 → 不调用本库（如纯告知类、纪要的议定事项本身已含量化）
   └─ 是 → ① 识别文稿所属领域（通用政务领域 or 国企经营/党建）
           ② 到对应章取"指标维度 + 表述范式"
           ③ 输出"建议考核以下维度"并套用范式
           ④ 范式中的 XX / X% / 基期 一律留【待补充】，不填数
           ⑤ 衔接：生成后交 第 1 册第 2 编《公文质量检查手册》实效性项终检
```

**铁律**：指标是"尺子"，不是"数据"。AI 只递尺子，不替用户量。

## 1. 好指标的四条标准（公文语境下的 SMART）

| 标准 | 含义 | 反例（不合格） |
|---|---|---|
| **可量化** | 有数、有单位、有基准 | "提升服务水平"（无单位无数值） |
| **可对比** | 有同比 / 环比 / 对标基期 | "达到先进水平"（无基准） |
| **可分解** | 能落到责任单位 / 时间段 | 总目标宏大但无人承接 |
| **可考核** | 有口径、有来源、能核验 | "群众满意度提高"（无调查口径） |

> 一条指标若同时满足四条，才算"实效性"维度合格的目标。

## 2. 通用党政机关 · 指标维度库（按工作领域）

> 每个领域给出三类内容：**常用指标类型** / **表述范式** / **口径备注**（数据从哪来、谁来核）。

### 2.1 经济发展与产业
- **常用指标**：地区生产总值（GDP）增速、规模以上工业增加值增速、全社会固定资产投资额、社会消费品零售总额、一般公共预算收入、亩均产出、单位 GDP 能耗。
- **表述范式**：
  - "到 2027 年，地区生产总值突破 XX 亿元，年均增长 X% 以上。"
  - "规模以上工业增加值增长 X% 以上，固定资产投资完成 XX 亿元。"
- **口径备注**：GDP、固投、社零取自统计部门；一般公共预算收入取自财政；"亩均产出"需明确统计范围（工业用地 / 园区）。

### 2.2 项目建设与投资
- **常用指标**：新开工项目数、竣工项目数、省市重点项目投资完成率、项目开工率、前期手续办结时限。
- **表述范式**：
  - "全年新开工重点项目 XX 个，竣工 XX 个，投资完成率达到 X% 以上。"
  - "X 月底前完成 XX 项目前期手续审批。"
- **口径备注**：项目清单以发改部门年度计划为准；投资完成率 = 实际完成投资 / 计划投资。

### 2.3 营商环境
- **常用指标**：企业开办时限（压缩至 X 个工作日）、政务服务"一网通办"率、市场主体净增数、惠企政策兑现率、融资成本下降百分点。
- **表述范式**：
  - "企业开办全流程压缩至 X 个工作日内，政务服务网上可办率达到 X% 以上。"
- **口径备注**：时限类以牵头部门承诺为准；"可办率"需界定事项总数口径。

### 2.4 民生保障
- **常用指标**：城镇新增就业人数、城镇调查失业率（控制在 X% 以内）、基本养老保险参保率、义务教育巩固率、每千人口托位数、保障性住房筹建套数。
- **表述范式**：
  - "城镇新增就业 XX 万人，城镇调查失业率控制在 X% 以内。"
  - "新筹建保障性租赁住房 XX 套，每千人口拥有 3 岁以下婴幼儿托位数达到 X 个。"
- **口径备注**：就业、失业取自人社 / 统计；参保率取自社保经办机构。

### 2.5 生态环境
- **常用指标**：空气质量优良天数比率、PM2.5 浓度下降值、地表水优良断面比例、单位 GDP 二氧化碳排放降低率、森林覆盖率、生活污水集中处理率。
- **表述范式**：
  - "空气质量优良天数比率达到 X% 以上，PM2.5 浓度控制在 XX 微克 / 立方米以内。"
  - "地表水国省控断面优良比例稳定在 X% 以上。"
- **口径备注**：环境质量指标以生态环境监测数据为准；"降低率"须注明基期年份。

### 2.6 乡村振兴 / 三农
- **常用指标**：粮食播种面积、高标准农田新建面积、农村居民人均可支配收入增速、集体经济薄弱村消除数、农村饮水安全覆盖率、卫生厕所普及率。
- **表述范式**：
  - "新建高标准农田 XX 万亩，集体经济年收入 XX 万元以下薄弱村动态清零。"
  - "农村居民人均可支配收入增速高于城镇居民 X 个百分点。"
- **口径备注**：面积类以农业农村部门台账为准；"动态清零"须定义时间节点。

### 2.7 安全生产
- **常用指标**：生产安全事故起数 / 死亡人数下降率、重大事故隐患整改率、重点行业领域标准化达标率。
- **表述范式**：
  - "生产安全事故起数和死亡人数同比分别下降 X% 以上，重大事故隐患整改率达到 X%。"
- **口径备注**：事故数据以应急管理部门直报系统为准；下降率需注明统计周期。

### 2.8 社会治理与平安建设
- **常用指标**：矛盾纠纷化解率、信访积案化解率、刑事发案率、网格事件办结率、群众安全感满意度。
- **表述范式**：
  - "矛盾纠纷化解率达到 X% 以上，信访积案化解率不低于 X%。"
- **口径备注**：化解率 = 已化解数 / 受理总数；满意度需明确调查方式（第三方 / 窗口）。

### 2.9 党建与廉政
- **常用指标**：第一议题学习落实率、发展党员计划完成率、软弱涣散党组织整顿率、巡视巡察反馈问题整改率、党风廉政建设责任制考核达标率。
- **表述范式**：
  - "党委（党组）会议'第一议题'制度落实率达到 100%，巡视巡察反馈问题整改销号率达到 X% 以上。"
- **口径备注**：落实率以会议记录 / 台账核验；整改销号以巡视巡察机构认定为准。

### 2.10 深化改革
- **常用指标**：重点改革任务完成率、高频事项"一件事"集成数、放权赋权事项数、试点经验复制推广数。
- **表述范式**：
  - "年度 XX 项重点改革任务完成率达到 X% 以上，新增'一件事'集成服务 XX 项。"
- **口径备注**：任务清单以深改委年度要点为准。

## 3. 国有企业 · 经营指标口径库

> 国企文稿须"双线并行"：经营指标 + 党建指标（审计权重表：国企第一权重实效性、第二权重政治性）。

### 3.1 经营线（参照国资委"一利五率"考核框架）
> "一利五率"为国务院国资委对中央企业 / 地方国企的通用考核口径，可作为国企目标任务的权威标尺。

> **2026 年中央企业目标"两个确保、两个力争"**（国新办 2026-01-28）：确保增加值持续增长（力争与 GDP 增速相匹配）；确保"一利五率"（利润总额、营业收现率、净资产收益率、研发投入强度、全员劳动生产率、资产负债率）稳中向好（力争总体优化）。口径已随国资委调整，现金流指标改用"营业收现率"。

| 指标 | 含义 | 表述范式 | 口径备注 |
|---|---|---|---|
| **利润总额** | 一利：稳增长核心 | "全年利润总额达到 XX 亿元，同比增长 X% 以上。" | 取自决算；强调"含金量"（不含非经常性收益） |
| **净资产收益率（ROE）** | 资本回报效率 | "净资产收益率力争达到 X% 以上。" | 净利润 / 平均净资产 |
| **全员劳动生产率** | 人均产出 | "全员劳动生产率提高到 XX 万元 / 人·年。" | 增加值 / 平均从业人数 |
| **研发投入强度** | 创新投入 | "研发投入强度不低于 X%。" | 研发经费 / 营业收入 |
| **营业收现率** | 现金流质量 | "营业收现率保持在 X% 以上。" | 经营活动现金流净额 / 营业收入（2025 年起国资委将"营业现金比率"调整为"营业收现率"） |
| **资产负债率** | 控杠杆 | "资产负债率控制在 X% 以内。" | 负债总额 / 资产总额 |

- **国有资产保值增值率**："国有资本保值增值率达到 X% 以上。"（扣除客观增减因素后）
- **经济增加值（EVA）**："经济增加值（EVA）为正且逐年提升。"
- **对标指标**："主要效能指标对标行业先进水平，达到 / 优于行业 X 分位。"

### 3.2 党建线（国企专属，不可省）
- **第一议题落实率**："党委会议'第一议题'制度落实率 100%。"
- **党委前置研究重大事项占比**："重大经营事项经党委前置研究讨论比例 100%（落实'三重一大'决策制度）。"
- **党风廉政建设**："党风廉政建设责任制考核达标率 X% 以上，全年无违纪违法案件。"
- **基层党建**："基层党组织标准化规范化建设达标率 X% 以上。"

### 3.3 国企指标禁忌
- 不得把"加强党的领导"当经营指标（属政治表述，非量化目标）。
- 资产负债率、ROE 等须与上级考核口径一致，不得随意调整分母口径。
- 所有数值以财务决算 / 国资委批复为准，AI 不估数。

## 4. 指标表述范式（可直接套用的句式）

> 下列句式中的 XX / X% / 基期 均为占位符，由用户填实际值。

| 类型 | 句式 |
|---|---|
| **总量目标** | "到 202X 年，XX 达到 XX（单位），较 202X 年增长 X% 以上。" |
| **进度目标** | "X 月底前完成 XX 前期工作，X 月底前实现 XX 投入运行。" |
| **占比提升** | "XX 占比提高到 X% 以上 / 较 202X 年提升 X 个百分点。" |
| **清零目标** | "XX 问题（XX 年底前）实现动态清零。" |
| **倍增目标** | "实现 XX 翻一番 / 年均增长 X% 以上。" |
| **达标目标** | "XX 达标率达到 X% 以上，优于 / 达到行业平均水平。" |
| **约束目标** | "XX 控制在 X% 以内 / 不超过 XX（单位），为约束性指标。" |
| **对比目标** | "XX 指标进入全省 / 全国前 X 位 / 优于行业 X 分位。" |

**搭配原则**：一份文稿的目标任务宜"定量为主、定性兜底"——能用数的不用形容词，定性目标须可检验（如"形成 XX 长效机制"须配责任与时限）。

## 5. 指标与目标任务的衔接（要素②）

- **指标树结构**：总目标 → 分目标（按领域 / 责任单位）→ 单项指标（可考核）。
  - 例：总目标"高质量发展"→ 分目标"产业升级"→ 指标"规上工业增加值增长 X%"。
- **定量 + 定性搭配**：约束性指标用定量（硬杠杠），导向性目标可用定性但须可检验。
- **时限锚定**：每项指标须绑定完成时限（见要素⑤），跨年目标须注明基期与末年目标，避免"无基期增长"。
- **责任绑定**：每项指标须可分解到责任单位（见要素④），否则不可考核。

## 2. 三重一大 + 党委前置研究

> 国企文稿最易漏的程序性硬伤，合法性第一检查点。

### 2.1 三重一大（通用界定）
| 类别 | 通用范围 |
|---|---|
| 重大决策 | 发展战略、经营方针、改革重组、资产处置、年度预算 |
| 重要人事任免 | 中层以上经营管理人员任免、薪酬分配方案 |
| 重大项目安排 | 重大投资、融资、担保、工程建设 |
| 大额度资金运作 | 大额资金调动使用、预算外资金、超权限支出（具体额度由企业制度定） |

### 2.2 党委前置研究讨论（核心程序）
- **规则**：重大经营管理事项须经党委（党组）前置研究讨论后，再由董事会或经理层按职权决策。
- **定位区分**：党委"把关定向"（看政治方向、合规风险、社会责任），不代替董事会作经营决策。
- **通用前置事项（框架，非穷尽）**：贯彻执行党中央决策部署的重大举措；企业发展战略与重大改革；重要人事安排；重大项目与大额度资金；风险防范与安全生产重大问题；涉及职工权益的重要事项。

### 2.3 表述范式（必背）
- "经公司党委（党组）前置研究讨论，董事会（或经理层）审议决定……"
- "该事项属于'三重一大'范围，已按程序提交党委（党组）前置研究。"
- "严格落实党委（党组）前置研究讨论重大经营管理事项制度。"

**禁忌**
- 不得写"董事会决定后报党委备案"（顺序颠倒）。
- 不得把党委前置写成"形式审议""例行过会"。

- 【改正】"全面建设社会主义现代化国家，协调推进全面建设社会主义现代化国家、全面深化改革、全面依法治国、全面从严治党。"
- 【要点】政治表述须用"当前时"，停用已完成时态的旧提法。

**B2　机构名称不规范**
- 【病例】"根据发改委文件精神……"
- 【问题】政治性 / 表达性。首次出现须用全称"国家发展和改革委员会"或"XX 省发展和改革委员会"，不得用"发改委"简称（除非后文已定义）。
- 【改正】"根据《国家发展和改革委员会关于……的通知》（发改XX〔202X〕X号）……"
- 【要点】机构首次用全称，简称须先定义。

**B3　臆造提法**
- 【病例】"打造'五位一体'乡村振兴新格局。"
- 【问题】政治性。"五位一体"特指经济建设 / 政治建设 / 文化建设 / 社会建设 / 生态文明建设总体布局，不能套用到乡村振兴。
- 【改正】"统筹推进乡村产业、人才、文化、生态、组织振兴。"
- 【要点】固定提法不得挪作他用、不得拼接臆造。

#### 【合法性】

**B4　程序缺失（国企）**
- 【病例】"经董事会研究决定，启动 XX 重大投资项目。"
- 【问题】合法性。重大投资项目属"三重一大"，未经党委（党组）前置研究。
- 【改正】"经公司党委（党组）前置研究讨论，董事会审议决定启动 XX 重大投资项目。"
- 【要点】重大经营管理事项，党委前置在前、董事会决策在后。

**B5　越权发文**
- 【病例】"XX 市局文件要求各乡镇党委做好……"（部门给下级党委发指令）
- 【问题】合法性。部门未经授权不得向下级党委发指令性文件。
- 【改正】"XX 市局商请各乡镇党委……"或改由党委办公室统筹发文。
- 【要点】部门对党委，用"商请 / 函"，不用"要求"。

#### 【真实性】

**B6　编造数据**
- 【病例】"全年新增就业岗位 1.2 万个，同比增长 35%。"（无任何来源）
- 【问题】真实性（红线）。数据为 AI 编造，无用户提供、无可溯源。
- 【改正】"全年新增就业岗位【待补充：请提供真实数据及统计来源】。"
- 【要点】数据必须用户给、可溯源；没有就标待补充，绝不编。

**B7　张冠李戴**
- 【病例】"参考 XX 省 2024 年做法……"（实际引的是另一省）
- 【问题】真实性。引用对象与事实不符。
- 【改正】核实真实出处后引用，或删除该引用。
- 【要点】引用须核实地名 / 文号 / 年份，不得"想当然"。

#### 【逻辑性】

**B8　因果断裂**
- 【病例】"要加强培训，因此产值就能翻番。"
- 【问题】逻辑性。培训与产值翻番无必然因果，论据撑不住结论。
- 【改正】"通过开展 XX 培训提升操作技能，预计带动产能提升 X%（须有测算依据）。"
- 【要点】措施要能支撑目标，空因果不成立。

**B9　结构残缺**
- 【病例】通知只写"请各单位抓好安全生产"，无责任单位、无时限。
- 【问题】逻辑性 + 实效性。缺要素④责任、⑤时限，落不了地。
- 【改正】"请各单位于 X 月 X 日前完成安全生产大检查，由 XX 科牵头、各车间配合，检查结果于 X 月 X 日报送。"
- 【要点】部署类文种必备责任 + 时限，缺一不可。

#### 【表达性】

**B10　文种误用**
- 【病例】用"请示"向上级"报告工作进展"。
- 【问题】表达性。报告工作进展应用"报告"，请示用于请求批准事项。
- 【改正】改用"报告"文种，或拆分：进展用报告、需批准事项用请示（一文一事）。
- 【要点】请示 = 求批准；报告 = 报情况，不可混用。

**B11　标点数字错误**
- 【病例】"参加会议的有局领导，各科室，直属单位等 3 类人员。"
- 【问题】表达性。并列用顿号；"3"在公文中一般汉字"三"（非概数且非年份制式）。
- 【改正】"参加会议的有局领导、各科室、直属单位等三类人员。"
- 【要点】标点按国标；公文数字用法见 第 5 册《国标原文补编》。

#### 【实效性】

**B12　只部署无指标**
- 【病例】"持续提升营商环境水平。"
- 【问题】实效性。无量化目标、无可考核口径。
- 【改正】"企业开办全流程压缩至 X 个工作日内，政务服务网上可办率达到 X% 以上。"（本册第 3 编《量化指标体系库》 §2.3）
- 【要点】目标须可量化、可考核，见本册第 3 编《量化指标体系库》。

**B13　保障措施空泛**
- 【病例】"加强组织领导，确保工作落到实处。"
- 【问题】实效性。保障只写口号，无具体组织 / 资金 / 督导安排。
- 【改正】"成立由 XX 任组长的专项工作组，安排专项资金 XX 万元，实行月调度、季通报、年考核。"
- 【要点】保障要具体，不能只写"加强领导"。

#### 【安全性】

**B14　敏感信息未脱敏**
- 【病例】汇报中直接列出信访人姓名、身份证号、具体住址。
- 【问题】安全性（一票否决）。含个人隐私，须脱敏。
- 【改正】"涉及信访事项按保密规定处理，隐去信访人个人信息后专题汇报。"
- 【要点】涉密、隐私、未公开敏感数据，一律脱敏或标注密级。

## 3. 高频病文 Top 速查（生成前避坑）

1. 只部署不考核（实效性）
2. 政治表述过时 / 臆造（政治性）
3. 数据无来源、靠编（真实性红线）
4. 文种误用（表达性）
5. 机构名称不规范 / 简称乱用（政治性 / 表达性）
6. 责任单位、时限双缺（逻辑性 + 实效性）
7. 国企漏党委前置（合法性）
8. 保障措施空话（实效性）
9. 涉密 / 隐私未脱敏（安全性）
