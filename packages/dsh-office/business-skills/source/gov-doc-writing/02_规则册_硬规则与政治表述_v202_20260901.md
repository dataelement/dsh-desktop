### 1. 公文定义与 15 个法定文种

**公文定义**（条例第三条）：公文是党政机关实施领导、履行职能、处理公务的具有特定效力和规范体式的文书，是传达贯彻党和国家的方针政策，公布法规和规章，指导、布置和商洽工作，请示和答复问题，报告、通报和交流情况等的重要工具。

**15 个法定文种及适用边界**（条例第八条原文 + 使用要点）

| 序 | 文种 | 条例原文适用情形 | 使用要点与易错提示 |
|---|---|---|---|
| 1 | 决议 | 适用于会议讨论通过的重大决策事项 | 必须经会议讨论通过；个人无权签发 |
| 2 | 决定 | 对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项 | 奖惩、撤改变更用"决定"，不用"通报" |
| 3 | 命令（令） | 公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员 | 层级高，一般机关少用 |
| 4 | 公报 | 公布重要决定或者重大事项 | 面向社会公开，如统计公报、会议公报 |
| 5 | 公告 | 向国内外宣布重要事项或者法定事项 | 面向国内外，级别高；一般性告知用"通告"或"通知" |
| 6 | 通告 | 在一定范围内公布应当遵守或者周知的事项 | 有约束力，限特定范围 |
| 7 | 意见 | 对重要问题提出见解和处理办法 | **多向行文**，上行、下行、平行均可 |
| 8 | 通知 | 发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文 | 使用频率最高；"批转"下级、"转发"上级或不相隶属 |
| 9 | 通报 | 表彰先进、批评错误、传达重要精神和告知重要情况 | **表彰先进用"通报"不用"决定"**（奖惩并用时决定偏重处分、通报偏重教育） |
| 10 | 报告 | 向上级机关汇报工作、反映情况，回复上级机关的询问 | **不得夹带请示事项**；属"阅件" |
| 11 | 请示 | 向上级机关请求指示、批准 | **必须一文一事、事前行文、单头主送**；属"办件" |
| 12 | 批复 | 答复下级机关请示事项 | 有请示才有批复，被动行文 |
| 13 | 议案 | 各级人民政府按照法律程序向同级人民代表大会或者人民代表大会常务委员会提请审议事项 | 主体限于政府→人大 |
| 14 | 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项 | 平行文；**向不相隶属的主管部门请求批准用"函"不用"请示"** |
| 15 | 纪要 | 记载会议主要情况和议定事项 | 会议产物，不单独对外发指令 |

> ⚠️ **高频错误**：①向不相隶属机关请求批准误用"请示"；②"报告"里夹带请示事项；③"请示"一文多事；④"公告""通告""通报"混用。

### 2. 公文格式 18 个要素（条例第九条）

公文一般由以下部分组成：

| 序 | 要素 | 编排要点 |
|---|---|---|
| 1 | 份号 | 公文印制份数的顺序号。**涉密公文应当标注** |
| 2 | 密级和保密期限 | 涉密公文按程度标注"绝密""机密""秘密"及期限 |
| 3 | 紧急程度 | 紧急公文标注"特急""加急"；电报标注"特提""特急""加急""平急" |
| 4 | 发文机关标志 | 发文机关全称或规范化简称 + "文件"二字；联合行文可并用或单用主办机关 |
| 5 | 发文字号 | 发文机关代字 + 年份 + 发文顺序号；**联合行文用主办机关发文字号** |
| 6 | 签发人 | **上行文应当标注签发人姓名** |
| 7 | 标题 | **由发文机关名称、事由和文种组成** |
| 8 | 主送机关 | 主要受理机关，用全称、规范化简称或同类型机关统称 |
| 9 | 正文 | 公文主体 |
| 10 | 附件说明 | 附件顺序号和名称 |
| 11 | 发文机关署名 | 署全称或规范化简称 |
| 12 | 成文日期 | 署会议通过或负责人签发日期；**联合行文署最后签发机关负责人签发日期** |
| 13 | 印章 | 有发文机关署名的应加盖印章并与署名机关相符；有特定发文机关标志的普发性公文和电报可不盖章 |
| 14 | 附注 | 印发传达范围等需说明事项 |
| 15 | 附件 | 正文的说明、补充或参考资料 |
| 16 | 抄送机关 | 除主送外需执行或知晓的其他机关 |
| 17 | 印发机关和印发日期 | 送印机关和送印日期 |
| 18 | 页码 | 页数顺序号 |

### 3. 版式与排版参数

**用纸与版面**
- 用纸：国际标准 A4 型（297mm × 210mm）
- 页边距：上 3.7cm，下 3.5cm，左 2.8cm，右 2.6cm
- 每页 22 行，每行 28 字；段落固定值 28 磅
- 文字颜色：无特殊说明均为黑色
- 双面印刷，左侧装订（平订，两钉外订眼距版面上下边缘各 70mm，与书脊距离 3—5mm）

**字体字号**

| 部位 | 字体 | 字号 |
|---|---|---|
| 标题 | 方正小标宋简体 | 二号 |
| 主送机关 | 仿宋 GB2312 | 三号 |
| 正文 | 仿宋 GB2312 | 三号 |
| 一级结构（一、） | **黑体** | 三号 |
| 二级结构（（一）） | **楷体** | 三号 |
| 三级及以下（1. （1）） | 仿宋 GB2312 | 三号 |
| 页码 | 宋体 | 四号（数字左右各一条一字线） |

**编排细则**
- 标题：顶格居中；多行时排成**梯形或菱形**，不得排成长方形或沙漏形；回行词意完整
- 主送机关：标题下空一行，居左顶格；回行仍顶格；末尾标全角冒号
- 正文：首页必须显示正文；主送机关下一行，每自然段左空 2 字，回行顶格
- 附件说明：正文下空一行左空二字排"附件"，后标全角冒号+名称，**名称后不加标点**
- 成文日期：右空 4 字，阿拉伯数字标全，年份全称，月日不编虚位（1 不写 01）
- 发文机关署名：在成文日期之上，以日期为准居中
- 印章：端正居中下压署名和日期，顶端不压正文
- 附件：另面编排，"附件"二字及顺序号用三号黑体顶格排左上角第一行

### 4. 行文规则（条例第十三至十七条）

**总原则**：行文应当确有必要，讲求实效，注重针对性和可操作性。

**通用规则**
- 行文关系根据**隶属关系和职权范围**确定
- **一般不得越级行文**；特殊情况越级的，应同时抄送被越过的机关

**向上行文（6 条）**
1. 原则上主送一个上级机关，根据需要抄送相关上级和同级机关，**不抄送下级机关**
2. 党委、政府部门向上级主管部门请示、报告**重大事项**，应经本级党委、政府同意或授权；属部门职权范围内的事项直接报送
3. 下级机关的请示事项如需以本机关名义向上级请示，**应当提出倾向性意见后上报，不得原文转报**
4. **请示应当一文一事**；不得在报告等非请示性公文中夹带请示事项
5. 除上级机关负责人直接交办事项外，**不得以本机关名义向上级机关负责人报送公文，不得以本机关负责人名义向上级机关报送公文**
6. 受双重领导的机关向一个上级行文，必要时抄送另一个上级机关

**向下行文（5 条）**
1. 主送受理机关，根据需要抄送相关机关；重要行文应同时抄送发文机关的直接上级
2. 党委、政府的办公厅（室）根据授权可向下级党委、政府行文；**其他部门和单位不得向下级党委、政府发布指令性公文**；需经政府审批的具体事项，经政府同意后可由职能部门行文，**文中须注明已经政府同意**
3. 党委、政府部门在各自职权范围内可以向下级党委、政府的相关部门行文
4. 涉及多个部门职权的事务，**部门之间未协商一致的不得向下行文**；擅自行文的，上级应责令纠正或撤销
5. 上级向受双重领导的下级行文，必要时抄送该下级的另一个上级

**联合行文与平行**
- 同级党政机关、党政机关与其他同级机关必要时可以联合行文
- **属于党委、政府各自职权范围内的工作，不得联合行文**
- 党委、政府的部门依据职权可以相互行文
- **部门内设机构除办公厅（室）外不得对外正式行文**

### 5. 公文拟制要求（条例第十九条）

公文起草应当做到：
1. 符合党的理论路线方针政策和国家法律法规，完整准确体现发文机关意图，并同现行有关公文相衔接
2. 一切从实际出发，分析问题实事求是，所提政策措施和办法切实可行
3. 内容简洁，主题突出，观点鲜明，结构严谨，表述准确，文字精练
4. **文种正确，格式规范**
5. 深入调查研究，充分进行论证，广泛听取意见
6. 公文涉及其他地区或者部门职权范围内的事项，起草单位必须征求相关地区或者部门意见，力求达成一致
7. 机关负责人应当主持、指导重要公文起草工作

### 6. 请示与报告的 8 点区别（高频考点）

| 比较项 | 请示 | 报告 |
|---|---|---|
| 1. 侧重点 | 提出问题和请求指示、批准 | 汇报工作、陈述意见或建议 |
| 2. 行文目的 | 请求上级批准或解决问题 | 让上级了解下情、便于指导 |
| 3. 行文时间 | **必须事前行文** | 事后或事情发展过程中 |
| 4. 内容要求 | **只能一文一事** | 可一文一事，也可一文数事 |
| 5. 报送要求 | 一般只写一个主送机关 | 可报送一个或多个上级机关 |
| 6. 标题 | 写明"请示"，不写"报告" | 写明"报告"，不写"请示" |
| 7. 结束语 | "妥否，请批示""特此请示，请予批准"，**须明确要求回复** | "特此报告"，**一般不写要求答复的词语** |
| 8. 处理结果 | **办件**，上级应及时批复 | **阅件**，一般不必件件答复 |

### 7. 结构层次序数规范

- 层次顺序：`一、` → `（一）` → `1.` → `（1）`
- 三层结构可用：`一、` / `（一）` / `1.`
- 二层结构可用：`一、` / `（一）` 或 `一、` / `1.`
- 一级用黑体，二级用楷体，三级及以下用仿宋 GB2312
- **二级标题换行分段时不使用句号**；如使用句号则不换行分段

### 8. 标点符号 12 个常见错误

| # | 错误类型 | 错误示例 | 正确写法 |
|---|---|---|---|
| 1 | 书名号/引号并列用顿号分隔 | 《预防未成年人犯罪法》、《义务教育法》 | 《预防未成年人犯罪法》《义务教育法》 |
| 2 | 数值与起止年限连接号不规范 | （2015-2018年）；3-5年 | （2015—2018年）一字线；3～5年 浪纹线 |
| 3 | 并列分句用逗号统领 | 各司其职、互相配合，工商部门负责…；工信部门负责… | 各司其职、互相配合；工商部门负责…；工信部门负责… |
| 4 | 分项已含句号末尾再用分号 | 一是养老保险安置。…保险；二是医疗保险安置。… | 各自独立成句，末尾不用分号 |
| 5 | 同一形式括号套用 | （责任单位：各镇（街道）） | [责任单位：各镇（街道）] |
| 6 | 阿拉伯数字次序点号不当 | 1、督促…；（1）、督促… | 1．督促…；（1）督促… |
| 7 | 图表说明文字末尾用句号 | 注：…统计为新口径。 | 注：…统计为新口径 |
| 8 | 发文年号括号不规范 | ×发[2018]X号 | ×发〔2018〕X号（**六角括号**） |
| 9 | 书名号内用顿号停顿 | 《××省物价局、××省财政厅关于…的批复》 | 《××省物价局　××省财政厅关于…的批复》（用空格） |
| 10 | 句内括号末尾用标点 | （领导小组组长由常务副区长兼任。） | （领导小组组长由常务副区长兼任） |
| 11 | 附件名称后加标点 | 附件：1.××领导小组成员名单； | 附件：1.××领导小组成员名单 |
| 12 | 二级标题换行分段用句号 | （一）整合监管职能和机构。↵为减少监管环节… | （一）整合监管职能和机构↵为减少监管环节… |

### 9. 数字用法要点

- 成文日期、印发日期：**阿拉伯数字**标全，年份全称，月日不编虚位
- 发文字号年份：阿拉伯数字 + 六角括号，如〔2026〕
- 结构层次序数、词词组中的数字、惯用语：**汉字数字**（如"三个方面""十四五"）
- 统计数据、百分比、金额、时间（非起止）：阿拉伯数字
- 相邻两个数字连用表示概数用汉字（如"三五天"），非概数用阿拉伯数字

> 注：本条为常规用法摘要，精确规则以《出版物上数字用法》GB/T 15835-2011 为准，**待抓取原文核验**。

### 10. 质检清单（生成后逐项自查）

依据条例第二十条审核重点，生成公文后必须逐条过：

**A. 合规性**
- [ ] 行文理由是否充分，行文依据是否准确
- [ ] 内容是否符合党的理论路线方针政策和国家法律法规
- [ ] 是否完整准确体现发文机关意图
- [ ] 是否同现行有关公文相衔接
- [ ] 所提政策措施和办法是否切实可行
- [ ] 涉及其他地区或部门职权的事项是否经过协商并达成一致

**B. 文种与格式**
- [ ] 文种是否正确（对照第 1 节 15 文种适用边界）
- [ ] 标题三要素是否完整（发文机关+事由+文种）
- [ ] 主送机关是否规范、是否违规抄送下级
- [ ] 上行文是否标注签发人
- [ ] 请示是否一文一事、是否夹带在非请示文中
- [ ] 成文日期、署名、印章位置是否规范

**C. 文字技术**
- [ ] 人名、地名、时间、数字、段落顺序、引文是否准确
- [ ] 文字、数字、计量单位、标点符号用法是否规范（对照第 8、9 节）
- [ ] 结构层次序数是否规范（对照第 7 节）
- [ ] 是否有错别字、重复表述、空话套话
- [ ] 政治表述是否使用标准提法

**D. 事实层（人工必填项，AI 不得编造）**
- [ ] 所有数据是否由人工提供且来源可靠
- [ ] 政策依据文号是否真实准确
- [ ] 具体事例、人名、地名是否核实
- [ ] 是否存在涉密内容需脱敏

# 第 2 编　L0 政治表述规范库

## 公文写作技能包 · L0 硬规则层 · 政治表述规范库

> **定位**：公文中政治性表述的规范与禁忌。政治性在六维质量模型中权重最高（党委机关第一权重），写错是硬伤不是瑕疵。
> **建立日期**：2026-08-31
>
> ⚠️ **使用时限与核实要求**
> - 第 1、2、3 节（核心提法、会议届次、机构名称）为**常态规范**，但党的全国代表大会、中央全会召开后会更新，**每年须核对最新表述**

### 1. 核心政治提法规范（不得简写、不得改写）

#### 1.1 指导思想与理论体系

| 标准表述 | 常见错误 |
|---|---|
| 习近平新时代中国特色社会主义思想 | ❌ 简写为"新思想"（除已在前文出现全称后的后续使用外）❌ 漏字、错序 |
| 马克思列宁主义、毛泽东思想、邓小平理论、"三个代表"重要思想、科学发展观 | ❌ 顺序颠倒 ❌ 漏项 |
| 党的二十大和二十届二中、三中、四中全会精神 | ❌ 写为"20大"❌ 届次错误（须含四中全会） |
| 习近平总书记重要讲话重要指示精神 | ❌ 写为"重要讲话精神"（漏"重要指示"） |

#### 1.2 固定提法（一字不能改）

| 类别 | 标准表述 |
|---|---|
| **政治建设** | "两个确立"（确立习近平同志党中央的核心、全党的核心地位，确立习近平新时代中国特色社会主义思想的指导地位）／"两个维护"／"四个意识"（政治意识、大局意识、核心意识、看齐意识）／"四个自信"（道路自信、理论自信、制度自信、文化自信）／"四个服从" |
| **战略布局** | "五位一体"总体布局（经济建设、政治建设、文化建设、社会建设、生态文明建设）／"四个全面"战略布局（全面建设社会主义现代化国家、全面深化改革、全面依法治国、全面从严治党） |
| **发展理念** | 新发展理念（创新、协调、绿色、开放、共享）／高质量发展／新质生产力／构建新发展格局 |
| **现代化** | 中国式现代化／国家治理体系和治理能力现代化／第二个百年奋斗目标／中华民族伟大复兴 |
| **为民** | 以人民为中心的发展思想／全过程人民民主／共同富裕／"四下基层" |
| **生态** | 绿水青山就是金山银山／山水林田湖草沙一体化保护和系统治理／碳达峰碳中和／美丽中国建设 |
| **党建** | 全面从严治党／新时代党的建设总要求／新时代党的组织路线／不敢腐、不能腐、不想腐／"四种形态"／中央八项规定精神 |
| **改革开放** | 全面深化改革／高水平对外开放／共建"一带一路"／推动构建人类命运共同体 |
| **法治** | 全面依法治国／法治政府、法治社会 |

> **易错点**："四个全面"中的第一项自十九届五中全会起已由"全面建成小康社会"更新为"**全面建设社会主义现代化国家**"，仍写旧表述即错误。

1. **首次用全称**，括注"（以下简称××）"，后续可用简称

3. **不得跨文沿用简称**：新公文首次出现仍需全称

### 3. 领导人职务与排序

#### 3.1 基本原则

1. **以官方最新公布顺序为准**，不得凭印象排序
2. 首次出现用**完整职务**，后续可简称"××同志"
3. **已卸任或调离的领导人不加职务**，称"××同志"
4. 多位领导人并列时，按**公布的排序**排列，不按姓氏笔画、不按年龄
5. 报道活动时用"出席""主持""讲话""致辞"等规范动词，不用"亲自出席""亲自视察"

#### 3.2 职务表述规范

| 场景 | 规范 | 禁止 |
|---|---|---|
| 引用讲话 | "××省委书记××指出" | ❌ "××书记说" ❌ "××老板表示" |
| 职务+姓名 | 中共××市委书记××× | ❌ 姓名在前职务在后（正式公文） |
| 已卸任 | ×××同志 | ❌ 仍标原职务 |
| 多个职务 | 按主要职务在前，兼职在后 | ❌ 罗列全部兼职 |

### 4. 禁用与慎用表述

> 来源：《新华社新闻信息报道中的禁用词和慎用词（2016 年 7 月修订）》＋公文实践补充。
> **该版本需核对最新修订**，以下为公文场景最常触犯的部分。

#### 4.1 涉及领导干部（公文高频）

| 禁用/慎用 | 正确表述 |
|---|---|
| ❌ "亲自"（领导出席、视察、批示） | ✅ 直接写"出席""调研""批示" |
| ❌ "隆重召开"（一般性会议） | ✅ "召开"；仅党中央国务院重要会议可用"隆重召开" |
| ❌ "老板"（称领导干部、国企负责人） | ✅ 职务或"××同志" |
| ❌ "重要讲话""重要指示"随意使用 | ✅ 有明确层级依据时才用 |
| ❌ "XX王""XX之父""领军人物"等夸张称谓 | ✅ 客观职务或"专家""带头人" |

#### 4.2 评价类（公文高频）

| 禁用 | 原因 | 正确做法 |
|---|---|---|
| "最佳""最好""最著名""最先进""全国第一""首创""率先" | 极端评价，需权威依据 | 有依据的可写"位居全省前列""较上年提升X位"等可验证表述 |
| "根治""药到病除""安全无副作用""国家级新药" | 绝对化承诺 | 用客观数据表述 |
| "掀起高潮""打一场人民战争""攻坚战"滥用 | 过度军事化 | 视正式程度选用，"攻坚战"仅在有明确部署时使用 |

#### 4.3 称谓类

| 禁用 | 正确表述 |
|---|---|
| "残废人""独眼龙""瞎子""聋子""傻子""呆子""弱智" | 残疾人、盲人、聋人、智力障碍者 |
| "影帝""影后""巨星""天王""男神""女神" | 著名演员、著名艺术家 |
| "农民工"（部分场合慎用） | 可用"进城务工人员" |
| "下岗工人" | 可用"失业人员""就业困难人员" |

#### 4.4 语言风格类

| 禁用 | 说明 |
|---|---|
| 网络低俗用语、脏话、黑话 | 明确规定禁用，公文中一律不得出现 |
| "哇噻""给力""牛""666""yyds"等网络流行语 | 公文须庄重规范 |
| 生造词、字母缩写（TMD、NB、PK等） | 除专业术语外一律不用 |
| 空话套话堆砌 | 如"高度重视""营造氛围"无后续内容支撑 |

#### 4.5 公文特有的表述禁忌

| 禁忌 | 说明 |
|---|---|
| 滥用"战略""工程""体系""机制" | 无实质内容支撑的大词 |
| 数字造假、凑整 | 数据须与统计口径一致 |
| "基本上""大体上""差不多" | 公文中应给准确表述 |
| 同一材料前后数据矛盾 | 常见硬伤，须交叉核验 |
| 引用政策依据不标文号或文号错误 | 必须核实原文 |

### 5. 涉港澳台表述（政治红线，不得变通）

| 禁止表述 | 正确表述 |
|---|---|
| ❌ "中港""中台""两岸三地"（部分场合慎用） | ✅ "内地与香港""大陆与台湾""海峡两岸" |
| ❌ 把台湾称为"国家"，或使用"中华民国""国立" | ✅ "中国台湾地区""台湾地区" |
| ❌ 把香港、澳门称为"国家"或"海外" | ✅ "中国香港特别行政区""中国澳门特别行政区" |
| ❌ "台湾政府""台湾当局"（除非特定引用场合且加引号） | ✅ "台湾地区有关方面" |
| ❌ "中港合资""中澳合作"（易生歧义，与澳大利亚混淆） | ✅ "内地与香港合资" |
| ❌ 将港澳台与"国家"并列统计 | ✅ 单独列示 |

**固定表述**：一个中国原则、"九二共识"、和平统一、一国两制、爱国者治港、爱国者治澳、港澳台同胞、反"独"促统

### 6. 民族宗教表述（政治红线）

| 禁止 | 正确做法 |
|---|---|
| 使用旧称、蔑称（如"回回""蛮夷"等） | 使用规范族称 |
| 将民族问题简单归结为其他问题 | 按中央关于民族工作的统一表述 |
| 涉及宗教随意评价教义教规 | 使用规范宗教名称：佛教、道教、伊斯兰教、天主教、基督教 |
| 炒作涉民族宗教敏感事件 | 一律按主管部门口径 |

**固定表述**：中华民族共同体意识、铸牢中华民族共同体意识、民族团结进步创建、依法管理宗教事务、坚持我国宗教中国化方向
