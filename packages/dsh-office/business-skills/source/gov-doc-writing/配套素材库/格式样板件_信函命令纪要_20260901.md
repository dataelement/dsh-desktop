# 格式样板件：信函 · 命令 · 纪要（配套素材）

> 版本：v1　|　建立日期：2026-09-01　|　归属：公文写作技能包 · 配套素材库
> 依据：GB/T 9704-2012《党政机关公文格式》附录 A（信函格式）、附录 B（命令/令格式）、附录 C（纪要格式）
> 说明：本文件全部使用占位符（`〖〗`、`XXX`、`XXXX年X月X日` 等），**不涉及任何真实单位名称、文号、密级与联系人**。复制时按实际情形替换占位符，红色线/字体等版式要素已在注释中标注，供排版核验。

---

## 一、信函格式（GB/T 9704-2012 附录 A）

### 版面要素与规则
- **发文机关标志**：由发文机关全称或规范化简称加"文件"或"函"字组成，红色，居中排布，上边距为 30mm。
- **红色分隔线（武文线）**：发文机关标志下 4mm 处印一条红色双线，线长均为 170mm，中心线压 22mm 版心中心线；**上粗下细**为武文线（首页），**上细下粗**为文武线（末页）。
- **发文字号**：顶格居左编排，与最后一条红色分隔线（文武线）间距为 3 号汉字高度（约 8mm）。
- 标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章格式同一般公文；**首页不显示页码，由第 2 页起显示**。
- **版记**：抄送机关置于最后一条红色分隔线（文武线）之下，左右各空一字编排。

### 样板（信函首页 + 末页）

```
┌──────────────────────────────────────────────┐
│             〖发文机关全称或规范化简称〗函          │  ← 红色，居中，上边距30mm
│                                                  │
│══════════════════════════════════              │  ← 武文线（上粗下细，距标志下4mm）
│〖发文机关简称〗函〔2026〕X号                        │  ← 顶格居左
│                                                  │
│           关于〖事由〗的函                          │  ← 标题，红色分隔线下空二行
│                                                  │
│〖主送机关全称〗：                                  │
│                                                  │
│  正文……（一文一事，语言平实得体，尾语据函种选用   │
│  "特此函告 / 特此函复 / 敬请函告 / 特此致函"等）。  │
│                                                  │
│  附件：1.〖附件名称〗                              │
│                                                  │
│                          〖发文机关全称或规范化简称〗 │  ← 署名右空二字
│                             2026年X月X日           │  ← 成文日期右空四字
│                   （加盖发文机关印章，压成文日期）   │
└──────────────────────────────────────────────┘
                          ……（第2页起显示页码）……
┌──────────────────────────────────────────────┐
│══════════════════════════════════              │  ← 文武线（上细下粗）
│  抄送：〖抄送机关全称或规范化简称〗                  │  ← 版记，左右各空一字
│  〖发文机关办公厅/室〗2026年X月X日印发              │
└──────────────────────────────────────────────┘
```

> 提示：信函格式与"文件格式"最大区别在于**用红色双线代替红色反线（文头红线）**，且首页无页码。商洽、询问、答复、审批等不相隶属机关行文一律用函（见`05_格式册`）。

## 二、命令（令）格式（GB/T 9704-2012 附录 B）

### 版面要素与规则
- **发文机关标志**：由发文机关全称加"命令"或"令"字组成，红色，居中排布。
- **令号**：在发文机关标志下空二行居中编排（如"第X号"），令号下空二行编排正文。
- **签发人**：正文下空二行右空二字编排签发人职务、签名章（签名章左空二字标注签发人职务），签名章用红色；签名章下空一行右空二字编排成文日期。
- **版记**：命令（令）的版记置于正文（或附件）之后，抄送机关、印发机关等要素同一般公文。

### 样板（命令/令）

```
┌──────────────────────────────────────────────┐
│              〖发文机关全称〗命令                    │  ← 红色，居中
│                                                  │
│                      第X号                        │  ← 令号，居中，标志下空二行
│                                                  │
│                                                  │
│  〖标题：关于……的命令（可省略"命令"二字）〗          │  ← 令号下空二行
│                                                  │
│  正文……（写明命令事项、执行要求，语言庄重、措辞     │
│  权威，一般不分章条或仅分少量条款）。                 │
│                                                  │
│                                                  │
│                              〖签发人职务〗         │  ← 正文下空二行，右空二字
│                                （签名章·红色）       │  ← 左空二字标职务
│                              2026年X月X日          │  ← 签名章下空一行，右空二字
│                                                  │
│  ────────────────────────────────────          │
│  抄送：〖抄送机关〗                                  │  ← 版记
│  〖发文机关办公厅/室〗2026年X月X日印发              │
└──────────────────────────────────────────────┘
```

> 提示：命令（令）仅限公布行政法规和规章、宣布施行重大强制性措施、嘉奖有关人员等法定情形（《党政机关公文处理工作条例》第八条），一般机关不得随意使用。

## 三、纪要格式（GB/T 9704-2012 附录 C）

### 版面要素与规则
- **纪要标志**：由"×××××会议纪要"组成，红色，居中排布，上边距为 30mm。
- **文号**：在纪要标志下空二行，居中编排"××××纪要〔2026〕X号"，文号下印一条红色分隔线。
- **参会人员**：出席、请假、列席人员名单可置于正文之后（或版记之前），标注姓名、职务。
- **正文**：记载会议主要情况和议定事项，一般采用"会议认为 / 会议指出 / 会议决定 / 会议要求 / 会议强调"等规范表述引领各段。
- **成文日期、印发机关**：置于版记或正文之后；纪要**不加盖印章**。

### 样板（会议纪要）

```
┌──────────────────────────────────────────────┐
│            〖XX会议全称〗会议纪要                    │  ← 红色，居中，上边距30mm
│                                                  │
│              〖XX〗纪要〔2026〕X号                 │  ← 标志下空二行，居中
│══════════════════════════════════              │  ← 红色分隔线
│                                                  │
│  2026年X月X日，〖召开会议的单位/领导〗在〖地点〗     │  ← 导语：时间+主体+地点
│  主持召开〖会议名称〗。〖参会范围简述〗出席会议，     │
│  〖列席/请假人员〗列席（请假）。会议〖议程简述〗，    │
│  现纪要如下：                                      │
│                                                  │
│  一、〖议题一名称〗                                │
│  会议认为，……（统一思想认识）                      │
│  会议指出，……（明确形势与任务）                    │
│  会议决定，……（形成具体决议）                      │
│  会议要求，……（部署落实责任与时限）                │
│                                                  │
│  二、〖议题二名称〗                                │
│  ……（同上结构）                                    │
│                                                  │
│  ────────────────────────────────────          │
│  出席：〖姓名、职务〗                               │  ← 参会人员
│  请假：〖姓名、职务〗                               │
│  列席：〖姓名、职务〗                               │
│                                                  │
│  〖召开会议的单位/办公室〗                          │  ← 署名（不盖章）
│  2026年X月X日印发                                 │
└──────────────────────────────────────────────┘
```

> 提示：纪要的"会议认为/指出/决定/要求/强调"五段式是固定语用范式，顺序可按实际调整；**议定事项必须可执行、可督办**，与`03_结构册`的"检验标准"要素呼应。纪要不盖章、不主送（仅抄送需要知晓的单位）。

## 四、三格式对比速查

| 维度 | 信函格式 | 命令（令）格式 | 纪要格式 |
|------|----------|----------------|----------|
| 红色标识 | 双线（武文线/文武线）代替红线 | 发文机关+"命令/令"红字 | "会议纪要"红字 |
| 发文字号位置 | 顶格居左（首页） | 无常规字号，用"第X号"令号居中 | "××纪要〔2026〕X号"居中 |
| 首页页码 | 不显示，自第2页起 | 显示 | 显示 |
| 署名/印章 | 发文机关署名+印章 | 签发人职务+红色签名章 | 召开会议单位署名，**不盖章** |
| 典型尾语 | 特此函告/复/致函/敬请函告 | 无（以令文收束） | 无（以议定事项收束） |
| 适用文种 | 函 | 命令（令） | 纪要 |

> 本样板件仅提供版式与占位结构，具体字体字号（如发文机关标志用红色小标宋体）、页边距（上37mm/下35mm/左28mm/右26mm）、行距等精确数值以 GB/T 9704-2012 原文及`05_格式册_国标原文补编`为准。
