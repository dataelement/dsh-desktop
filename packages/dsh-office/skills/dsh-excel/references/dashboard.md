# 多图仪表盘与分析案例

## 执行入口

`office_template(template_id="port-cargo")` 提供「青岚港货物流向与作业效率」：5 张工作表、8 张原生图表、365 天和 2,190 条模拟装卸记录。

`office_template(template_id="bio-assay")` 提供「荧光酶活性筛选与批次质控」：4 张工作表、4 张原生图表、三板条件格式热力图和 288 个模拟孔位。

将返回的 authoring.language/source/inputs 与新 output_file 交给 office_build，再执行 office_recalculate 和 office_preview。随包 checks.json 的关键预期值由原始 JSON 独立计算。替换输入时同步调整预期值、日期范围、公式边界和图表范围。

`office_template(template_id="annual-business")` 提供六表年度经营模型，可用 office_inspect 检查、office_excel_edit 修改和 office_recalculate 重算。该样例最初通过独立制表工具制作，在 DSH 中复用现有工作簿结构。

## 版式与数据

摘要指标、密集趋势和核对明细围绕同一问题组织。每张图注明时间与单位，指标和图表引用相同原始材料。原生图表引用单元格，原始输入与公式分开，完整观测值保留在 XLSX。明细预览展示可读范围，并写明记录数量；用户可在 Excel 中检查全部记录。

港口示例的一条记录表示一次进港卸货或出港装货作业；货物吨数与 TEU 分别统计。季度等泊时间按全部作业求均值；吨每小时使用匹配的总货量与总作业时长。装卸总量按作业计量，转运货物可能重复计入。

实验示例先按本板空白和溶剂对照归一化，再对三个独立批次均值计算样本 SD（n=3）。技术重复用于评价板内测量稳定性。演示 CV 阈值可调整，高 CV 数据保留并标记复核；浓度响应保留实测点，有回升时提示逐段复核 50% 区间。

## 验证

提供独立数值核对：港口总量、进港占比、等泊时间、作业计数；实验孔数、批次数、归一化活性与跨批次 SD。修改一条原始输入并重算，确认摘要、相关表与图表缓存一起更新。检查每张图的引用、长序列点数、条件格式与所有预览页。实际工具执行、模型自主生成和 Excel/WPS 编辑保存重开分别记录。
