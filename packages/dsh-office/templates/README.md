# Office 案例

当前内置三份 Word 案例和三份 Excel 案例。卡片展示完整代表页的缩略图，点击打开只读弹窗。Word 按页滚动，Excel 按工作表切换并连续滚动；关闭后返回当前任务。

| 类型 | 案例 | 内容与执行 |
| --- | --- | --- |
| Word | 中国现制咖啡市场调研报告 | 7 页研究报告；固定公开披露输入与 JavaScript 制作源码 |
| Word | 小米汽车研究报告 | 12 页研究样稿；完整原件与版式说明 |
| Word | 中国中车质量安全月活动通知 | 用户提供原件及嵌入字体；4 页实际渲染预览 |
| Excel | 年度经营与客户分析 | 6 表、11 张原生图表；纯白背景、模拟数据和计算明细；20 段连续预览 |
| Excel | 青岚港货物流向与作业效率 | 5 表、8 张原生图表、2,190 条模拟装卸记录；原始输入、Python 源码与独立核对值 |
| Excel | 荧光酶活性筛选与批次质控 | 4 表、4 张原生图表、288 个模拟孔位；批次统计与质控、完整输入和 Python 源码 |

咖啡、港口与实验案例通过 DSH 自有基础 Skill 的 office_template → office_build → office_recalculate（Excel）→ office_preview 链路生成。年度经营工作簿最初由独立制表工具制作，作为现有文件通过 DSH 读取、局部修改和重算。模型自主规划与原生 Office 编辑保存保留独立验收记录。

catalog.json 记录每个源文件、说明与预览的哈希。案例准备操作经过工作区政策和审计。公文原件及待补充项保留；ZIP 校验约束为原文件 32 MiB、单条目 16 MiB、展开总量 64 MiB，并检查条目数及 CRC。

186 个业务 Skill 在 business-skills 中独立注册；案例库与 Skill 目录分别管理。
