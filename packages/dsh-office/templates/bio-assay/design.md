# 荧光酶活性筛选与批次质控

## 版式与执行

3 批次、288 个模拟孔位；剂量响应、技术重复 CV、跨批次统计与三板热力图。4 张工作表。

使用 DSH 自有基础 Skill 和 office_template 返回的 authoring 执行 office_build。保持输入顺序与修订哈希。生成后调用 office_recalculate（Excel）与 office_preview，核对所有展示页。当前案例通过 DSH 工具直接生成；模型自主规划的结果需另行验收。

基础流程 dsh-excel，业务方法 dataset-health-audit、data-viz-gen。inputs/bio.json 为 3 个独立模拟批次，每批 96 孔，每剂量 8 个技术重复。先按本板空白与溶剂对照归一化，再计算三个批次均值的样本 SD（n=3）；技术重复用于评价板内稳定性。所有 288 孔保留，一处模拟偏差在 CV 与热力图中呈现。15% CV 为可调整的演示阈值。50% 区间公式先检查曲线方向，有回升时提示逐段复核。原始读数预览前 39 行；4 张原生图表和 3 板条件格式热力图可随数据更新。方法来源见工作簿。
