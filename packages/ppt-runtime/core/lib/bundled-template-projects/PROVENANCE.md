# Bundled editable PPTD projects

## Green Pulse · 绿色活力配图模板

Green Pulse is a DSH-authored sample template for image-assisted presentations. It contains 22 editable layouts, 17 declared image slots, 11 bindings to native editable masks and one native editable diagram. Names, narrative copy, sample values, colors and layout files in this directory were written for Green Pulse.

These photographs were created by the DataElement team. © DataElement. All rights reserved. They may ship with the template. Shared constraints remain: fictional people and organizations, no brands or logos, no embedded text or watermarks, and natural editorial photography. The per-asset generation record is in [`dsh-green-pulse/media/provenance.json`](dsh-green-pulse/media/provenance.json).

The packaged project is copied into the active workspace through the audited template-copy tool. The signed package remains the reusable source.
