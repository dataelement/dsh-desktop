# Bundled editable PPTD projects

## Green Pulse · 绿色活力配图模板

Green Pulse is a DSH-authored sample template for image-assisted presentations. It contains 22 editable layouts, 17 declared image slots, 11 bindings to native editable masks and one native editable diagram. All names, narrative copy, sample values, colors and photographs in the distributed template were created for Green Pulse. Generated-photo metadata lives in `dsh-green-pulse/media/provenance.json`.

The original reference remains the property of its respective rights holder. This bundled project supports local validation. The template source, metadata and preview images are packaged locally, and runtime copies are created inside the active workspace through the audited template-copy tool.
