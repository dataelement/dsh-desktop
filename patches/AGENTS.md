# 第三方补丁约束

继承根目录规则。补丁是可追踪的兼容层，每一项都产生上游升级成本。选型与 slot 契约以 [Patch 与 Plugin 规范](../docs/patch-plugin-contract.md) 为准；本文件补充补丁文件的维护流程。

- 补丁限定到目标包和必要行为；记录对应上游版本、问题、回归测试及移除条件。不得夹带格式化、生成噪声或无关依赖修改。
- 不以长期复制上游业务模块代替兼容补丁。不要依赖未验证的内部字段、事件或返回协议。
- 临时编辑 `node_modules` 后必须生成并提交可重放的 patch；只改安装目录不算交付。
- 验证全新 `npm ci` 的 postinstall 能完整应用补丁，并运行相关行为/契约测试。涉及 UI、Remote 或插件加载时补充真实 Harness 流程。
- 上游升级要逐项判断补丁是否已被修复、接口是否变化；删除过时补丁并调整相关测试，不机械修补上下文使其勉强应用。
- 不把补丁文件纳入普通源代码格式化；lint 应针对实际源码或重放结果，不能直接解析 diff 为 JS。
